# Student Expense Tracker

## Problem Statement

Students often find it difficult to monitor their daily spending because expenses are made across different categories such as food, transportation, education, shopping, and entertainment. Maintaining handwritten records or using unorganized notes can lead to inaccurate tracking and poor financial awareness.

The Student Expense Tracker is a Java-based console application designed to help students record, manage, search, delete, and summarize their daily expenses in a structured manner.

## Scope of the Project

The project focuses on developing a simple and user-friendly offline expense management system using Java Object-Oriented Programming concepts.

The application supports:

* Adding new expenses
* Viewing all recorded expenses
* Searching expenses using keywords
* Deleting expenses using expense IDs
* Categorizing expenses
* Generating category-wise and total expense summaries
* Saving expense data locally using a text file

The project is intended for individual student use and does not include online banking integration, cloud synchronization, or multi-user authentication.

## Target Users

* College students
* School students
* Individuals managing daily personal expenses
* Users who need a basic offline expense tracking system

## High-Level Features

1. Expense recording
2. Expense categorization
3. Expense viewing
4. Expense searching
5. Expense deletion
6. Summary report generation
7. Local data persistence
8. Input validation and error handling

## Expected Outcome

The system will provide users with a structured way to track their expenses and understand their spending patterns through a simple console-based interface.
